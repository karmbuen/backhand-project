# One-handed Backhands: A Statistical Perspective on their Competitive Relevance

For this project, I used R to conduct a comparative analysis of one-handed and two-handed backhands on the ATP Tour. Here is the published [HTML Report](https://rpubs.com/kob4zh/project).

Special thanks to [Jeff Sackmann](https://github.com/JeffSackmann) and the [Tennis Abstract](https://tennisabstract.com), whose match and rank data were integral in developing this project. Please refer to the end of my HTML report for further references.

## Development

Please feel free to review my code and test it out for yourself.

My HTML report was created using [Project_html.rmd](https://github.com/karmbuen/backhand-project/blob/807c21ec200f67f6ea57809b44cc429f56afed44/Project_html.rmd). I created the [First Shiny App](https://kob4zh.shinyapps.io/project_p1/) using [p1_code.R](https://github.com/karmbuen/backhand-project/blob/807c21ec200f67f6ea57809b44cc429f56afed44/p1_code.R), and I created the [Second Shiny App](https://kob4zh.shinyapps.io/project_p4/) using [p4_code.R](https://github.com/karmbuen/backhand-project/blob/807c21ec200f67f6ea57809b44cc429f56afed44/p4_code.R). The rest of the files are data and pictures used throughout my code.
